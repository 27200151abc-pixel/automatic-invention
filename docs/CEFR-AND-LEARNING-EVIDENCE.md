# CEFR scope and learning evidence
The A1 label describes the intended beginner level of this prototype; it is not an official CEFR certification or validated placement assessment. A2, B1, B2, C1, and C2 currently appear only as roadmap labels and have no lessons implemented.

## Learning design
- Short prompts with one keyed answer.
- Immediate correctness feedback and a brief explanation.
- Repeated exposure to basic vocabulary and beginner grammar.

## Limitations and next steps
The eight items are illustrative, not a psychometrically validated test. Before claiming CEFR alignment, map each item to specific descriptors, review with qualified teachers, pilot with learners, check ambiguity and distractors, and document revisions. Consider spaced review and varied exercise types after the core content is quality-reviewed.
